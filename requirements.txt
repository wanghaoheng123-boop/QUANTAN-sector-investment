# Q110-T7b (2026-09-06) — this line exists because the constraint was previously
# invisible. `tradingagents` published only wheels with `Requires-Python: >=3.12`,
# so on 3.11 pip reported "from versions: none" and the manifest looked BROKEN
# rather than mis-targeted. (That package is no longer in this manifest — see
# below — but the floor stays: 3.13 is the interpreter the suite is verified on.) Nothing in this repo
# declared a minimum interpreter — no pyproject.toml, no setup.py, no
# .python-version — so the requirement lived transitively inside a dependency
# and was discoverable only by failing. The CI pytest job pinned 3.11 and did
# exactly that. Under 3.13 the full manifest installs clean and the suite is
# 132 passed / 0 skipped.

# pytest suite tests the sidecar's helpers without importing the package.
